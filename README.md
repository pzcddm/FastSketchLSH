## FastSketchLSH

FastSketchLSH is a research project for using Fast Similarity Sketch (a very efficient MinHash-like method) to estimate Jaccard similarity and to accelerate large-scale deduplication. It includes a high-performance C++/SIMD extension and Python tooling for benchmarking and simulation.

## Install the C++ extension

Build and install the native extension first:
```bash
cd fastsketchlsh_ext
pip install .
```

This provides the Python module `FastSketchLSH` with classes like `FastSimilaritySketch` and `FastSimilaritySketchSIMD`.

## Python requirements (for benchmarks/simulations/tests)

Install the Python packages used by tests, benchmarks, and simulations:
```bash
pip install -r requirements.txt
```

## Quick start (Python)

```python
# Estimate Jaccard using Fast Similarity Sketch (SIMD-accelerated)
from FastSketchLSH import FastSimilaritySketchSIMD

set_a = {f"a-{i}" for i in range(10000)}
set_b = {f"a-{i}" for i in range(5000)} | {f"b-{i}" for i in range(5000)}

sketcher = FastSimilaritySketchSIMD(sketch_size=128)
sig_a = sketcher.sketch(set_a)
sig_b = sketcher.sketch(set_b)

# Simple estimator used across the repo
from prototype.simulation.util import estimate_jaccard
print("estimated jaccard:", estimate_jaccard(sig_a, sig_b))
```

## Compare performance with other MinHash methods

Use the tests in `test/` to measure sketch generation time and accuracy against popular alternatives:

- **datasketch** MinHash
- **rensa** implementations: CMinHash (cmins) and RMinHash (rmins)

Recommended entry point:
```bash
python3 test/test_comparison.py
```

This script sweeps multiple `k` and `n`, compares error and speed, and writes results to `records/sketch_comparison_results.csv`.

## Simulations (accuracy/variance)

The `prototype/simulation/` folder contains small experiments showing that Fast Similarity Sketch has even lower variance, which means higher accuracy for Jaccard estimation at the same sketch size.

Example utilities and plots:
- `prototype/simulation/util.py`: set generation and Jaccard utilities used everywhere
- `prototype/simulation/figures/`: example figures comparing distributions

## End-to-end Deduplication Benchmark

The `evaluation/` directory contains scripts for benchmarking the entire deduplication pipeline (sketching, LSH, and evaluation) on datasets with ground truth labels. The main script, `benchmark_groundtruth.py`, compares `FastSketchLSH` against `datasketch` and `rensa` on the `pinecone/core-2020-05-10-deduplication` dataset from Hugging Face.

### Usage Example

To run the benchmark with default parameters:
```bash
python3 evaluation/benchmark_groundtruth.py
```

You can customize the run with different parameters. For example, to use a different LSH threshold and use 50% of the dataset:
```bash
python3 evaluation/benchmark_groundtruth.py --lsh_threshold 0.9 --ratio 0.5
```

The script outputs performance metrics like precision, recall, accuracy, and runtime for each method, and provides a side-by-side comparison.

## Project layout

- `fastsketchlsh_ext/`: C++17/AVX2/AVX-512 extension exposing `FastSketchLSH` to Python (install with `pip install .`).
- `prototype/src/`: Reference Python wrappers for other sketches (datasketch, rensa cmins/rmins) and the FastSimilaritySketch helpers.
- `prototype/simulation/`: Reproducible small-scale simulations and utilities.
- `exps/`: One-off notebooks/scripts for exploratory experiments (imports from `prototype`).
- `test/`: Accuracy and speed comparisons; use `test_comparison.py` for end-to-end benchmarking.
- `records/`: CSVs and plots generated by benchmarks.
